# Retail Sales Dashboard

This is my first real Power BI project. I wanted to stop just watching tutorials and actually build something I can show to a company.

The data was a retail sales file with 12,000+ rows. Honestly it was a mess at first, dates were wrong, some customer names were duplicated, and I had to clean a lot of it in Power Query before I could even start.

## What I found

- Total Revenue was around 984M, which was higher than I expected
- The biggest customer was Electricalsara Stores, by a big gap from the second one
- Delhi NCR was the top market, almost double the others
- Men's Footwear was selling the most, which surprised me

If I was the manager, I would focus more on Delhi NCR and on that top customer, because losing them would hurt a lot.

## What I used

Power BI, Power Query for cleaning, and some DAX for Revenue and Profit. Still learning DAX, some measures took me 2-3 tries to get right.
